# Stage18 CatBoost Ordered Boosting Open(18단계 캣부스트 순서 부스팅 개방)

## Decision(결정)

Stage18(18단계)를 `18_model_family_challenge__catboost_ordered_boosting_scout`로 열었다.

효과(effect, 효과): CatBoost(`Categorical Boosting`, 범주형 부스팅/캣부스트) ordered boosting(순서 부스팅)을 Stage17(17단계) XGBoost(`Extreme Gradient Boosting`, 익스트림 그래디언트 부스팅) 이후의 독립 model family(모델 계열) 주제로 탐색할 수 있다.

## Boundary(경계)

이 결정은 topic open(주제 개방)과 experiment design(실험 설계)만 만든다. run(실행), model artifact(모델 산출물), KPI(`Key Performance Indicator`, 핵심 성과 지표), MT5(`MetaTrader 5`, 메타트레이더5) runtime_probe(런타임 탐침), alpha quality(알파 품질), edge(거래 우위), baseline(기준선), promotion(승격), runtime authority(런타임 권위)는 만들지 않는다.

## Next(다음)

첫 후보는 `run12A_catboost_ordered_boosting_characteristic_scout_v1`다.

효과(effect, 효과): 다음 작업은 CatBoost(캣부스트) 고유 축이 보이는지 먼저 확인하고, 보이지 않으면 Stage18(18단계)을 길게 끌지 않는다.
