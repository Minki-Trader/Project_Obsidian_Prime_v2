# 2026-05-02 Stage16 QDA Class Covariance Open(16단계 QDA 클래스별 공분산 개방)

## Decision(결정)

Stage16(16단계)를 `16_model_family_challenge__qda_class_covariance_scout`로 연다.

효과(effect, 효과): QDA(`Quadratic Discriminant Analysis`, 이차 판별 분석)를 Stage15(15단계) LDA(`Linear Discriminant Analysis`, 선형 판별 분석)의 내부 반복이 아니라 class-specific covariance(클래스별 공분산)를 묻는 독립 model-family topic(모델 계열 주제)으로 다룬다.

## Boundary(경계)

Stage16(16단계) 개방은 stage transition(단계 전환)과 experiment design(실험 설계)만 뜻한다. alpha quality(알파 품질), edge(거래 우위), promotion candidate(승격 후보), operating promotion(운영 승격), runtime authority(런타임 권위), selected baseline(선택 기준선)을 만들지 않는다.
