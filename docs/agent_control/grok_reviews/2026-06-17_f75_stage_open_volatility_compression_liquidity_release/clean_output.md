## Classification(분류)

**`accepted(수용)`**

F75를 F74 수리(repair, 수리)가 아니라 **새 가설 생명주기(new hypothesis lifecycle, 새 가설 생명주기)**로 여는 방향은 스냅샷만으로도 타당합니다. F74 부정 기억(negative memory, 부정 기억)은 “마이크로버스트(microburst, 마이크로버스트) 표면에서 scout clue(탐색 단서) 0 / meaningful candidate(의미 후보) 0 / 약한 런타임 경제성(weak runtime economics, 약한 런타임 경제성)”인데, F75는 임계값·세션 미세조정이 아니라 **상류 메커니즘(upstream mechanism, 상류 메커니즘)**—변동성 압축(volatility compression, 변동성 압축) + 유동성 방출(liquidity release, 유동성 방출)—을 바꾸겠다고 명시합니다. 축(axes, 축)도 라벨·거래 형태·위험 로직·세션 게이트가 분리되어 있고, scout 성공/실패 기준이 F74 실패 패턴을 직접 거부합니다. 5단계 중간 검토(five-stage retrospective, 5단계 중간 검토)가 `not_due(아직 아님)`이므로 F75 개방을 그 이유로 막을 근거도 없습니다. 주장 경계(claim boundary, 주장 경계)도 개방·탐색 수준에 맞습니다.

`needs_local_verification(로컬 검증 필요)`로 **개방 자체**를 보류할 필요는 없습니다. 다만 실행 단계에서 피처 가용성(feature availability, 피처 가용성), 라벨 밀도 하한(density floor, 밀도 하한), MT5 Runtime Probe(MT5 런타임 탐침) 트리거는 Codex 로컬 검증 대상으로 남깁니다.

---

## Drift risk(드리프트 위험)

**축이 넓은 1차 scout(넓은 축 탐색)가 “밀도 통과(density pass, 밀도 통과) + 약한 PF/DD(수익 팩터/손실폭)” 반복으로 수렴하는 것.**  
압축 문맥 3종, 방출 트리거 4종, 라벨 모드 4종, 세션 게이트 3종을 한 번에 넓게 훑으면 F74처럼 표면은 채워지지만 scout clue(탐색 단서)가 다시 0에 가까워질 수 있습니다.

---

## Repair priority(수리 우선순위)

**F75B 첫 proxy scout(프록시 탐색)부터 SL/TP(손절/익절)·MAE/MFE(최대/최소 불리·유리 이동)를 라벨·프록시 시뮬레이션에 내장할 것.**  
F74E 약한 validation/OOS 경제성은 사후 수리(after-the-fact repair, 사후 수리)로는 안 잡혔으므로, “의미 있거나 근접 신호(near-meaningful signal, 근접 의미 신호)”가 나오기 전에 거래 형태·위험 로직을 라벨 설계에 고정하는 것이 우선입니다.

---

## Do-not-repeat note(반복 금지 메모)

**F74식 “축/밀도/패리티(parity, 동등성) 통과를 보존 단서(preserved clue, 보존 단서)로 축하하면서 scout meaningful candidate(의미 후보) 0과 validation/OOS `PF≈1.1x` 수준의 런타임 경제성을 약한 실패로만 기록하고 같은 표면을 더 깎는” 패턴을 반복하지 말 것.**  
F75에서는 proxy가 PF/DD/trades-per-day(일거래 수) 균형 또는 near-meaningful surface(근접 의미 표면)를 못 보이면, 같은 단계 안에서 메커니즘·라벨 모드 축을 바꾸거나 실패로 닫고 임계값·세션만 더 돌리지 말 것.

---

**Claim boundary(주장 경계):** 위 분류는 F75 **개방 제안(opening proposal, 개방 제안)**에 대한 외부 2차 의견(second opinion, 2차 의견)이며, 완성(completion, 완성)·기준선(baseline, 기준선)·승격(promotion, 승격)·런타임 권위(runtime authority, 런타임 권위)·실거래 준비(live readiness, 실거래 준비)·Goal Achieve(목표 달성)를 만들지 않습니다.
