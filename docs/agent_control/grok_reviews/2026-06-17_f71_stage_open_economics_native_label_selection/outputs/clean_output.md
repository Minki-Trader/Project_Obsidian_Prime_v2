# F71 Stage Open Review — Grok Second Opinion(외부 2차 의견)

**Classification(분류): `needs_local_verification(로컬 검증 필요)`**

Direction(방향) is **accepted in principle(원칙상 수용)** — F71 is a real axis shift(축 전환), not a cosmetic rename(표면 이름만 바꾼 수리). But Codex(코덱스) should not open execution(실행 개방) until a few local anchors(로컬 고정점) are confirmed.

---

## 1. Is F71 sufficiently new relative to F70?(F70 대비 F71이 충분히 새로운가?)

**Mostly yes(대체로 예)** — if discipline holds(규율이 지켜지면).

| F70 pattern(F70 패턴) | F71 proposed shift(F71 제안 전환) |
|---|---|
| Post-selection throttling(선택 후 제한): tape, threshold, cooldown, quota | Pre-selection economics(선택 전 경제성): label + selection objective |
| Macro/regime surface(거시/장세 표면) as main lever(주 레버) | Feature removal/recombination(피처 제거/재조합) under economics target(경제성 목표 아래) |
| Bridge/risk/tape repair(연결/위험/테이프 수리) | Lifecycle PnL + MFE/MAE + adverse path in label(생명주기 손익 + 최대 유리/불리 + 불리 경로를 라벨에 내장) |

**Risk of same-surface drift(같은 표면 표류 위험):** F71 can collapse back into F70 if trade-shape/risk/regime work becomes **post-hoc throttling(사후 제한)** or if “economics-native” is only a new model on the **old direction/first-hit label(기존 방향/최초 도달 라벨)**.

**Verdict(판정):** Novelty claim(새로움 주장) is credible(타당) at design level(설계 수준). Execution novelty(실행 새로움) is **unproven until F71B proxy(프록시 탐색)** shows the label/selection axis actually moved KPI(핵심 지표가 실제로 움직임).

---

## 2. Which axis should lead?(어떤 축이 주도해야 하나?)

**Lead pair(주도 쌍): `label/target(라벨/목표)` → `selection objective(선택 목표)`**

Reason(이유): Retrospective pivot(중간 검토 방향 전환) is economics-native **model/label/selection**. Until the target names **realized lifecycle economics(실현 생명주기 경제성)**, other axes only re-rank the old problem(기존 문제를 다시 순위 매김).

**Recommended order(권장 순서):**

1. **Label/target** — cost/slippage/swap-aware PnL, MFE/MAE balance, adverse path stress
2. **Selection objective** — joint density/PF/DD gate, not probability rank alone
3. **Trade shape + risk logic** — entry/exit/hold, SL/TP, DD guard **inside label evaluation(라벨 평가 안)**
4. **Feature set** — removal/recombination **after** label spec is frozen enough to test(라벨 정의가 어느 정도 고정된 뒤)
5. **Model family** — linear/EBM/LGBM/small NN only as **economics-target expressers(경제성 목표 표현기)**
6. **Regime/session split** — **evaluation slices(평가 조각)** only, never inherited gate(상속 게이트)

Do **not** lead with model family or features; that repeats F68–F70 “surface swap(표면 교체)” failure mode(실패 패턴).

## 3. What should Codex reject during F71?(F71에서 Codex가 거절할 것)

Reject immediately(즉시 거절):

- **F70 repeat(반복):** same macro/regime tape, threshold, cooldown, quota as primary lever
- **Probability-rank selection(확률 순위 선택)** without joint density/PF/DD contribution test
- **Sparse PF standalone(희소 수익 팩터 단독 판독)** without density-lift fracture test(밀도 상승 균열 시험)
- **Runtime probe as discovery(런타임 탐침을 주 탐색으로)** before proxy meaningful-candidate evidence(프록시 의미 후보 근거)
- **Bridge parity re-proof(연결 동등성 재증명)** as runtime probe purpose
- **Regime as single inherited filter(장세 단일 상속 필터)**
- **Post-hoc throttling labeled “economics”(사후 제한을 경제성이라 부르기)**
- **Model bake-offs(모델 대결)** that do not change label/selection definition
- Any path that implies **baseline / promotion / runtime authority / live readiness / Goal Achieve**

## 4. Local verification before acting(행동 전 로컬 검증)

Codex should verify locally(로컬에서 확인) **before F71A→F71B execution**:

| Check(확인 항목) | Why(이유) |
|---|---|
| F70 closeout negative memory(마감 부정 기억): exact surfaces tried(시도한 표면) | Anti-repeat guardrail(반복 방지) needs a concrete deny-list(거부 목록) |
| Operational definition of **joint density/PF/DD gate**(밀도/수익팩터/손실폭 공동 게이트) | Without this, “economics-native” is not measurable(측정 불가) |
| Label economics spec(라벨 경제성 명세): cost/slippage/swap, hold horizon, exit rules | Prevents silent old-label reuse(옛 라벨 재사용 은폐) |
| Density-lift fracture test protocol(밀도 상승 균열 시험 절차) | Blocks sparse-PF false wins(희소 PF 허위 승리) |
| Tier A / Tier B / combined recording path(티어 A·B·합산 기록 경로) | Paired-tier discipline(쌍 티어 규율) |
| Proxy scout infrastructure(프록시 탐색 인프라) for broad surface | F71B depends on runnable broad sweep(넓은 스윕 실행 가능) |
| Retrospective register(중간 검토 등록부): `not_due` + F66–F70 scope(범위) | Stage-open gate(단계 개방 게이트) |
| F71 lifecycle slots F71A–F71E in stage artifacts(단계 산출물) | Plan is not yet materialized locally(계획만 있고 자료는 미확인) |

Until these exist(위가 없으면): treat F71 as **plan-only open(계획만 개방)**, not scout-ready(탐색 준비 완료).

- **F70 authority stays zero(F70 권위 0 유지):** preserved clue + negative memory only
