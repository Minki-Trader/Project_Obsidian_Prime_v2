# Frontier53 Negative Memory(전선53 부정 기억)

- judgment(판정): `negative_memory_path_quality_proxy_did_not_transfer_to_runtime(부정 기억, 경로 품질 프록시가 런타임으로 전이되지 않음)`
- memory(기억): raw path-quality classifier(원천 경로 품질 분류기)는 proxy(프록시)에서 barely positive(간신히 양수)였고, MT5 runtime(런타임)에서 PF source(수익 팩터 원천)로 충분하지 않은지 기록한다.
- boundary(경계): 이 기억은 F53 후보에 대한 기록이며, 다른 PF source(수익 팩터 원천) 탐색을 금지하지 않는다.
