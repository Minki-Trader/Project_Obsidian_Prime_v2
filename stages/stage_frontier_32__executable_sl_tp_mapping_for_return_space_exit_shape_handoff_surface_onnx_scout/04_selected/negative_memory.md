# Frontier32 Negative Memory(전선32 부정 기억)

Negative memory(부정 기억): `f32_return_space_handoff_surface_failed_executable_sl_tp_raw_path_proxy(F32 수익률 공간 인계 표면은 실행 가능한 손절/익절 원천 경로 프록시에서 실패)`

Why limited(제한 이유): return-space caps(수익률 공간 한도)를 executable SL/TP path proxy(실행 가능한 손절/익절 경로 프록시)로 번역하자 path scout/seed/runtime candidate(경로 탐색/씨앗/런타임 후보)가 `0/0/0`로 0이었습니다.

Evidence(근거): best validation/OOS PF-density-DD(최상 검증/표본외 수익 팩터-밀도-손실폭)는 `1.043/5.962/9.665` and `0.948/6.687/17.336`입니다.

Do not repeat(반복 금지): return-space proxy(수익률 공간 프록시)의 좋은 숫자를 intrabar path(봉내 경로) 또는 MT5 runtime probe(MT5 런타임 탐침) 없이 ONNX readiness(온엑스 준비)로 과장하지 않습니다.
