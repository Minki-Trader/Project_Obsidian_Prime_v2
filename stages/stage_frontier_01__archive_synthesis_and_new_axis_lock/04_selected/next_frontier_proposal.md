# Next Frontier Proposal(다음 전선 제안)

Proposed stage id(제안 단계 ID): `stage_frontier_02__joint_objective_onnx_density_quality_scout`

This is a proposal(제안) only(전용). It does not open the stage(단계를 열지 않음) and does not select a baseline(기준선 선택 없음).

## Hypothesis(가설)

US100 M5(US100 5분봉)에서 four-axis joint objective(네 축 동시 목적)로 직접 학습한 ONNX(온엑스) surface(표면)는 density(밀도), PF(profit factor, 수익 팩터), DD(drawdown, 손실폭), curve smoothness(곡선 매끄러움)를 한 축씩 수리한 과거 루프보다 더 빨리 completion candidate(완성 후보)에 가까워질 수 있다.

## Why This Is New(신규성)

- It starts from a new hypothesis lifecycle(새 가설 생명주기) rather than Stage365 continuation(Stage365 연속).
- It treats Stage12~364(12~364단계) as bounded reference archive(제한 참조 보관소), not candidate inheritance(후보 상속).
- It uses archive DNR(보관소 반복 금지)을 objective design(목적 설계)에 직접 반영한다.
- It blocks one-axis advancement(한 축 전진)을 early(초기)부터 금지한다.

## First Packet Shape(첫 작업 묶음 형태)

1. Stage open(단계 개방) with Grok review(그록 검토). Effect(효과): hypothesis(가설), success criteria(성공 기준), claim boundary(주장 경계)를 external second opinion(외부 2차 의견)으로 비판받는다.
2. Proxy design(프록시 설계). Effect(효과): density/PF/DD/smoothness(밀도/수익 팩터/손실폭/매끄러움)를 동시에 보도록 score(점수)를 만든다.
3. Scout run(탐색 실행). Effect(효과): final completion gate(최종 완성 게이트)가 아니라 closeness-to-target(목표 접근도)을 본다.
4. WFO/stress gate(WFO/스트레스 게이트) only if scout clue(탐색 단서)가 충분하다. Effect(효과): 비싼 검증 전 Grok review(그록 검토)와 local verification(로컬 검증)을 거친다.
5. Runtime probe(런타임 탐침) only after handoff identity(인계 정체성)가 닫힌다. Effect(효과): proxy proof(프록시 증명)를 runtime authority(런타임 권위)로 세탁하지 않는다.

## Initial Success Read(초기 성공 판독)

Allowed early terms(초기 허용 표현):

- scout clue(탐색 단서)
- seed surface(씨앗 표면)
- runtime probe observation(런타임 탐침 관찰)
- completion candidate(완성 후보), only after proxy/WFO/stress/runtime(프록시/WFO/스트레스/런타임)이 같은 방향을 가리킬 때

Forbidden until full evidence(전체 근거 전 금지):

- completion(완성)
- baseline(기준선)
- promotion(승격)
- runtime authority(런타임 권위)
- live readiness(실거래 준비)
- Goal Achieve(목표 달성)
