# Stage 16 QDA Class Covariance Scout(16단계 QDA 클래스별 공분산 탐색)

Stage16(16단계)는 QDA(`Quadratic Discriminant Analysis`, 이차 판별 분석)의 class-specific covariance(클래스별 공분산)가 FPMarkets(에프피마켓) `US100` `M5` 데이터 계약(data contract, 데이터 계약) 위에서 어떤 training behavior(학습 행동), probability shape(확률 모양), signal density(신호 밀도)를 보이는지 확인하는 독립 주제다.

- independence(독립성): Stage15(15단계) LDA(`Linear Discriminant Analysis`, 선형 판별 분석)의 light shrinkage(약한 공분산 수축) 단서는 seed clue(씨앗 단서)로만 쓴다. baseline(기준선), selected variant(선택 변형), promotion(승격)으로 쓰지 않는다.
- purpose(목적): QDA(이차 판별 분석)의 covariance regularization(공분산 정규화), class-specific geometry(클래스별 기하), signal density(신호 밀도)를 얕게 읽는다.
- boundary(경계): alpha quality(알파 품질), edge(거래 우위), baseline(기준선), promotion(승격), runtime authority(런타임 권위)를 만들지 않는다.

효과(effect, 효과): Stage16(16단계)는 LDA(선형 판별 분석)와 같은 판별분석 계열(discriminant analysis family, 판별 분석 계열)이지만, 클래스별 공분산을 허용했을 때 같은 단서가 유지되는지를 따로 묻는다.
