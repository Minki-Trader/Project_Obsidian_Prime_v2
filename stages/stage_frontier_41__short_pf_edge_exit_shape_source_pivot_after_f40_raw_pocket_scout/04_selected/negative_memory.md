# Negative Memory(부정 기억)

F41 negative memory(부정 기억)는 exit shape(청산 형태)만으로 final target(최종 목표)에 충분히 접근하지 못했다는 점이다.

- seed_surface_count(씨앗 표면 수): 0
- runtime_probe_candidate_count(런타임 탐침 후보 수): 0
- runtime_probe_status(런타임 탐침 상태): `runtime_probe_ineligible_no_seed_or_runtime_candidate_after_f41_exit_shape_proxy`

Effect(효과): MT5 runtime probe(MT5 런타임 탐침)는 실행하지 않고 부적격으로 닫는다.
