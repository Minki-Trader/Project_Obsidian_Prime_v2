# Frontier58 Negative Memory(전선58 부정 기억)

- judgment(판정): `negative_memory_microstructure_friction_source_did_not_transfer(부정 기억, 미시구조 마찰 원천이 MT5로 전이되지 않음)`
- memory(기억): all-signal proxy(전체 신호 프록시)와 ONNX parity(온엑스 동등성)를 맞춘 뒤에도 MT5 validation/OOS(MT5 검증/표본외) PF(수익 팩터)는 `0.36` / `0.68`로 관찰됐다.
- do_not_repeat(반복 금지): microstructure friction survivability label(미시구조 마찰 생존성 라벨)만 바꾸고 execution economics(실행 경제성)를 MT5에서 확인하지 않는 방식으로 같은 수리를 반복하지 않는다.
- boundary(경계): F58 후보에 대한 economic transfer(경제성 전이) 기억이며, signal path failure(신호 경로 실패)나 다른 PF source(수익 팩터 원천) 탐색 금지를 뜻하지 않는다.
