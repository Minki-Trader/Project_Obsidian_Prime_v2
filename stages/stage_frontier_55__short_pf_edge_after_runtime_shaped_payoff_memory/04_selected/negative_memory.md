# Frontier55 Negative Memory(전선55 부정 기억)

- judgment(판정): `negative_memory_sparse_admission_runtime_veto_did_not_transfer(부정 기억, 희소 진입 허용 런타임 차단이 MT5로 전이되지 않음)`
- memory(기억): sparse admission runtime veto source(희소 진입 허용 런타임 차단 원천)가 MT5 runtime(런타임)에서 PF source(수익 팩터 원천)로 충분하지 않은지 기록한다.
- boundary(경계): F55 후보에 대한 기억이며, 다른 PF source(수익 팩터 원천) 탐색을 금지하지 않는다.
