# Frontier59 Negative Memory(전선59 부정 기억)

- judgment(판정): `negative_memory_long_axis_did_not_escape_friction_class(부정 기억, 롱 축이 마찰/경제성 붕괴 계열을 벗어나지 못함)`
- memory(기억): long-only proxy(롱 전용 프록시)와 ONNX parity(온엑스 동등성)를 맞춘 뒤 MT5 validation/OOS(MT5 검증/표본외) PF(수익 팩터)는 `0.46` / `0.58`로 관찰됐다.
- do_not_repeat(반복 금지): proxy PF near 1(프록시 수익 팩터 1 근처)과 perfect signal parity(완벽 신호 동등성)를 MT5 seed readiness(MT5 씨앗 준비)로 보지 않는다.
- do_not_repeat(반복 금지): raw direct p_long threshold(원천 직접 p_long 임계값), no lifecycle compression(생명주기 압축 없음), max_hold_bars 6(최대 보유 6봉), ATR SL/TP(ATR 손절/익절) 조합을 long-quality first proof(롱 품질 1차 증명)로 반복하지 않는다.
- do_not_repeat(반복 금지): direction flip(방향 전환)만으로 short-side economics collapse(매도 측 경제성 붕괴)를 해결했다고 보지 않는다.
- boundary(경계): F59 후보에 대한 economic transfer(경제성 전이) 기억이며, long-side exploration(롱 측 탐색) 전체 금지를 뜻하지 않는다.
