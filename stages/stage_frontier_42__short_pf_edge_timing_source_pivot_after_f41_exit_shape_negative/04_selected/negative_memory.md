# Negative Memory(부정 기억)

F42 negative memory(부정 기억)는 timing source(타이밍 원천)만으로 final target(최종 목표)에 충분히 접근하지 못했는지 또는 seed/runtime(씨앗/런타임) 후보가 없었는지를 기록한다.

- seed_surface_count(씨앗 표면 수): 0
- runtime_probe_candidate_count(런타임 탐침 후보 수): 0
- runtime_probe_status(런타임 탐침 상태): `runtime_probe_ineligible_no_seed_or_runtime_candidate_after_f42_timing_proxy`
