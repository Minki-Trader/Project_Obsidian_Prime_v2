# Negative Memory(부정 기억)

- stage(단계): `stage_frontier_61__non_long_axis_pf_source_after_friction_memory`
- judgment(판정): `negative_memory_side_allocation_failed_runtime_pf(부정 기억, 방향 배분 런타임 PF 실패)`
- failure_mode(실패 양식): `['side_allocation_pf_failed(방향 배분 PF 실패)', 'dd_not_compressed_under_10(DD 10 미만 압축 실패)', 'runtime_density_out_of_target(런타임 밀도 목표 이탈)']`
- reopen_condition(재개 조건): side allocation(방향 배분)을 다시 열려면 feature/source(피처/원천), runtime envelope(런타임 봉투), or parity evidence(동등성 근거)가 F61과 materially different(실질적으로 다름)해야 한다.
