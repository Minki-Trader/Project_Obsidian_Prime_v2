# Frontier56 Negative Memory(전선56 부정 기억)

- judgment(판정): `negative_memory_adverse_excursion_source_did_not_transfer(부정 기억, 불리 이동 회피 원천이 MT5로 전이되지 않음)`
- memory(기억): parity(동등성)는 signal_diff=0, feature_ready_diff=0으로 aligned(정렬)됐지만, proxy PF(프록시 수익 팩터) 1.05대가 MT5 runtime PF(런타임 수익 팩터) 0.46/0.74로 collapsed(붕괴)했다.
- do_not_repeat(반복 금지): proxy PF(프록시 수익 팩터) > 1과 ONNX parity(온엑스 동등성)를 MT5 edge transfer(MT5 우위 전이)로 간주하지 않는다.
- do_not_repeat(반복 금지): `f56b_adverse_excursion_extratrees_d6_l80_short_mae65_mfe55_q85` 변형은 proxy trades/day(프록시 거래/일) 약 3.2~3.5와 MT5 trades/day(MT5 거래/일) 약 7.6~7.8의 gap(차이)을 설명하지 않고 연장하지 않는다.
- boundary(경계): F56 후보에 대한 negative economic transfer(부정 경제성 전이) 기억이며, signal path failure(신호 경로 실패)나 다른 PF source(수익 팩터 원천) 탐색 금지를 뜻하지 않는다.
